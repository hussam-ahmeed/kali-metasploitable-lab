# Security Policy

## Scope

This repository documents an isolated educational penetration-testing lab using Kali Linux and Metasploitable2. The material is intended for systems that you own or are explicitly authorized to test.

## Responsible use

Do not use the commands, techniques, or findings in this repository against public services, third-party systems, production environments, or any network without written authorization. Keep intentionally vulnerable targets on an isolated host-only or equivalent network.

## Reporting a concern

If you find an accidentally published secret, private detail, or unsafe instruction in this repository, please do not exploit it. Open a private report through GitHub or contact the repository owner directly so the material can be removed or corrected.

## Secrets

Never commit passwords, API keys, private keys, internal IP addresses, or personal data. Revoke any credential immediately if it is exposed.
